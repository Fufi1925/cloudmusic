# Contributing

This repository is a **private, personal fork** of Liner (upstream: [tryliner/desktop](https://github.com/tryliner/desktop)).
It is not the upstream project and does not accept pull requests.

- Do not publish this repository, its builds or the APK/installer files: the [license](./LICENSE) only permits private,
  non-commercial use (§2) and forbids public distribution or binary releases of forks (§4b).
- Bug reports and feature requests belong to the upstream project, not here. Changes to the shared code base are best
  sent upstream (see the upstream `CONTRIBUTING.md`), because the [license](./LICENSE) only allows forks that contribute back.
- Keep the repository private and keep `android/keystore/` (signing key) out of version control.

See [NOTICE.md](./NOTICE.md) for attribution and [README.md](./README.md) for building the desktop app and the APK.
